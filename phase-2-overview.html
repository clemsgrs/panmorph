panmorph · computational pathology

Cross-organ transfer of genomic-biomarker morphology

Predicting MSI status from H&E whole-slide images, and asking the question prior work couldn't: when does the morphology learned in one organ carry to another — and how much is that worth?

Go / no-go gate  ·  PASSED

Where phase 2 starts

The gate established confound-free, organ-dependent cross-organ MSI transfer on frozen PRISM embeddings. Cohorts share zero tissue-source-sites and the target organ is never trained on — so neither sample size nor a site shortcut explains the signal.

Transfer is real but organ-dependent: GI↔GI transfers, the gynecological organ doesn't — even though it's individually predictable. That asymmetry is the conceptual core of phase 2.

The questions

RQ1 · primary

Value

How many local positives is a foreign organ worth? Converts the binary transfer result into a continuous substitution rate for scarce labels.

Fully powered today — measured within existing organ pairs.

RQ2 · secondary

Representation

Does the transfer survive — or improve under — a stronger representation? Two separable axes: head capacity and aggregation capacity.

De-risks the value result as not a capacity artifact.

RQ3 · parked

Mechanism

What governs whether transfer happens? A claim about variation across pairs — with one transferring pair, that's n≈1.

Blocked on adding organs; kept alive only as free byproducts.

The experiment spine

E1

Value measurement load-bearing

Simulate scarcity by subsampling a label-rich organ down a k-sweep, so a real organ-specific ceiling exists to check against. The few-shot lift over cold-start is the value.

  • Shared site-grouped out-of-fold scaffold → every curve point sits on the identical, site-clean test set
  • k counts positives, prevalence-matched (each draw carries negatives at the organ's natural rate) — an MSI label costs one assay per case
  • The lowest rungs (k=3–5 positives) are the genuinely-scarce few-shot regime — now measured against a real ceiling
  • Two warm-start bases: pooled (a strong general model) and single-source (which organ carries the value)
  • Formal test = the lift, against a within-source label-permutation null that controls the sample-size confound
  • Substitution rate k* reported as estimation, with a confidence interval
swap

Budget-matched swap secondary control

The dual of E1. Where E1 holds the source fixed and adds target labels ("how much does a little local data help on top of the foreign model?"), the swap holds the total budget fixed and trades source for target ("at equal labeling cost, is a local case worth more than a foreign one?"). Two different value questions — reported as distinct, never merged.

RQ2

Capacity ladder representation

Encoder frozen throughout; the variable is tile→slide aggregation.

  • MLP head first — settles whether a linear boundary is the bottleneck (cheap)
  • Then frozen-encoder + trainable MIL — so any gain is attributable to aggregation, not a bigger head
  • A control, not the headline — unless MIL cracks UCEC, flipping that wall from biology to aggregation
＋

Shared-subspace probe contingent

Runs only if the pooled base shows negative transfer (a non-sharer diluting the value curve). Goal: a source-only invariant projection that recovers the pooled-base curve to ≈ the best single-source base — a direct rebuttal of "multi-tissue training is a wash." Demoted from a pillar because it's underpowered with only two sharing organs.

How we keep it honest

Confound discipline

Carried over from the gate: cohorts share zero tissue-source-sites (structural, not harmonized away), and cross-validation is grouped by site so a site never appears in both train and test.

The right null

Significance is the few-shot lift against a within-source label-permutation null — it holds source data volume fixed and randomizes only labels, so a win means biology, not "more rows." (A prediction-swap permutation would readmit that confound.)

Substrate matched to question

Value measurement runs on a parameter-light, fixed-HP estimator with no per-run tune split — robust under scarcity, where a held-out tune set has no clean source. The trained-NN + tune-split machinery is reserved for the label-rich capacity ladder.

One honest AUC

Pooled out-of-fold scoring (never averaged per-fold), with a cheap safeguard: report it beside the averaged-per-fold number, and rank-normalize within fold if they diverge.
