# Agent triage labels

This repository uses the canonical agent workflow labels without aliases.

| Workflow state | GitHub label |
|---|---|
| Ready for an agent | `ready-for-agent` |
| Work in progress | `agent:in-progress` |
| Pull request open and under review | `agent:in-review` |
| Changes required before retry | `agent:needs-changes` |

Closed issues represent delivered work. Dependencies are recorded in each issue's
`## Blocked by` section.
