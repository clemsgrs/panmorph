PanMorph

Can a model that reads tumor slides from one organ detect the same mutation in another organ?

We tested this for MSI, a mutation status that decides whether a patient gets immunotherapy.
The answer so far: yes — for some organ pairs.

Done · the transfer is provenNext · measure its value

02Motivation

Why this question matters

MSI testing needs a lab assay. Predicting it directly from routine H&E slides would be cheaper and faster. But for many organs, we have very few labeled cases to train on.

The hope: borrow training data from other organs where labels are plentiful.

The catch: an early pilot seemed to confirm the hope — until we noticed that adding foreign organs also multiplied the training data 20-fold. More data helps any model. That proves nothing about organs.

So the real question became: is there genuine shared tumor morphology across organs — or just more data and hidden shortcuts?
03Data

Three organs from TCGA

Each patient is one slide embedding (from PRISM, a pathology foundation model) plus one MSI label.

One property makes this dataset special: the three cohorts come from completely different hospitals — zero overlap. So a model cannot succeed on a new organ by recognizing hospital fingerprints.

Prostate and bladder were considered too, but each has only ~3 MSI-positive cases. Not usable.

04Experiments

One clean test, decided in advance

The experiment is simple by design: train a small classifier on one organ, then test it on another organ it has never seen.

Before running anything, we wrote down what would count as success, and we guarded against the two ways to be fooled:

More data ≠ transfer

The target organ contributes zero training data. Any performance there must come from what the model learned elsewhere.

Hospital fingerprints ≠ transfer

Hospitals are recognizable in these embeddings — we checked. But the organs come from disjoint hospitals, so that trick cannot work here.

06Takeaway

Transfer exists, and it has structure

  • Colon ↔ stomach works, both ways. Biologically plausible: both are GI cancers with the same MSI mechanism.
  • Endometrium stands apart. MSI is predictable within it, but nothing transfers in or out. Transfer is organ-dependent — that is a finding, not a failure.
  • The controls held. Neither data volume nor hospital shortcuts explain the result.
The closest published study, using older methods, found no usable transfer on these same organs. Foundation-model embeddings changed the answer.

08Next · stronger models

Does a better model change the picture?

Everything so far uses the simplest possible setup: frozen embeddings plus a linear classifier. That was the right choice for a clean proof. It also leaves obvious headroom:

  • Swap in a newer foundation model (e.g. PRISM2).
  • Go below the slide level: a tile encoder with a trainable MIL aggregator, instead of one pre-pooled vector per patient.

The most interesting outcome would be a surprise: if a stronger model makes endometrium start transferring, its wall was a limitation of our representation — not of biology.
